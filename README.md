## 📦 Доступные сборки проекта:

### 1. ⚡ Hyzen Modded (Industrial & Magic)
* **Версия**: NeoForge 1.21.1
* **Модов**: 150+
* **Особенности**:
  * Полный технологический прогресс и автоматизация (Applied Energistics, Mekanism, Create).
  * Магические ветки и алхимия.
  * Защищенная общая экономика через серверный мост `HyzenBridge`.
  * Интегрированные голосовой чат (PlasmoVoice) и эмоции (Emotecraft, Figura).
  * Готовая эргономичная раскладка клавиш без конфликтов.

### 2. ⛏ Hyzen Vanilla SMP
* **Версия**: Fabric 1.21.4 (26.1.2)
* **Модов**: 60+
* **Особенности**:
  * Максимальная производительность (Sodium, Lithium, FerriteCore, C2ME).
  * Поддержка шейдеров (Iris Shaders).
  * Позиционный голосовой чат PlasmoVoice.
  * Кастомный зум (Wi-Zoom) и удобная сортировка сундуков.

## 🔄 Как устроены обновления:

* Все моды и конфигурации синхронизируются **автоматически** при каждом запуске.
* Личные настройки графики и раскладки клавиш (`options.txt`) **никогда не сбрасываются**.
* Все файлы проверяются по контрольным суммам **SHA256**.
* Прямое скачивание через распределенную CDN Fastly GitHub с высокой скоростью.
